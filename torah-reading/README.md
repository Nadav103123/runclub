# עולים לתורה – אב טיפוס (פרשת חיי שרה, נוסח אשכנזי)

אתר סטטי, בלי בנייה ובלי שרת. להרצה מקומית:

```bash
cd torah-reading
python3 -m http.server 8000   # ואז לפתוח http://localhost:8000
```

## מה יש באב הטיפוס
- **לימוד:** שבע העליות של הפרשה, בשלושה מצבים: עם טעמים, עם ניקוד, וכמו בספר תורה (בלי ניקוד).
  לחיצה על מילה מציגה את שם הטעם, אם הוא מפסיק או משרת, ואפשר לשמוע אותה.
- **סיפור והפניות:** לכל מקטע יש תקציר והפניות לפסוקים קשורים (עם קישור לספריא).
- **שמיעה:** "מנגינת הדגמה" בסינתיסייזר עם הדגשת מילה-מילה (ראו `js/tropes.js`).
- **שינון:** הסתרת מילים בשלוש רמות קושי וסימון "שיננתי" לכל פסוק.
- **בוחן טעמים:** זיהוי הטעם על מילה מהפרשה.
- **התקדמות:** נשמרת בדפדפן (`localStorage`).

## מקורות
- הטקסט (ניקוד וטעמים): Sefaria-Export, "Tanach with Ta'amei Hamikra", נחלת הכלל.
  אפשר לבנות מחדש בעזרת `tools/build_data.py`.

## חשוב לדעת (לפני שמראים לילדים)
1. **המנגינות הן הדגמה מקורבת בלבד** ולא מאושרות על ידי חזן. יש להחליף אותן בהקלטה אמיתית.
2. **התוכן בקובץ `data/content.js` (תקצירים, הפניות, הסברי הטעמים) הוא טיוטה** ודורש אישור רב או מורה.
3. **הקלטות:** הקלטות מהאינטרנט מוגנות בזכויות יוצרים, ולכן לא מורידים אותן ולא מטמיעים אותן בלי רשות.
   האפשרויות: חזן שמקליט במיוחד ונותן הרשאה בכתב, הקלטה ברישיון פתוח (Creative Commons), או רשות מפורשת מהמקליט.

## הצעדים הבאים
- הקלטת הפרשה על ידי חזן, ויצירת קובץ זמנים לכל מילה (כדי להחליף את הסינתיסייזר).
- הוספת ההפטרה והברכות.
- משוב על שירת התלמיד (הקלטה והשוואה, ובשלב מאוחר יותר זיהוי אוטומטי).
- התחברות משתמשים, מורה שרואה את התלמידים שלו, ותשלום.
- נוסחים נוספים (ספרדי, עדות המזרח).
